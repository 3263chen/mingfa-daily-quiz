# 法硕每日一题刷题（民法 + 法制史）

基于微博每日一题合集构建的静态刷题页，单文件、零后端、离线可用。

## 功能
- 双模块：民法（岳业鹏 每日一题）/ 法制史（龚成思 跟老龚刷个题），顶部一键切换，进度独立
- 抽 1 题 / 抽十题：做完十题显示正确率
- 只做错题、错题本、10 题刷题历史、重点标记
- 进度保存在浏览器本地
